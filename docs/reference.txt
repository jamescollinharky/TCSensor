Quick reference — NIR multi-band sensor (Arduino + serial)
=========================================================

Setup
-----
  pip install -r requirements.txt

Arduino multi-band cycle
------------------------
  Upload arduino/multi_band_cycle/multi_band_cycle.ino to Arduino Uno.
  Output: one CSV row per cycle: ms,1300,1460,1650,1720,1900 (merged time series).

Capture serial to CSV (Option B)
-------------------------------
  python scripts/capture_multi_band_serial.py -l
    List serial ports.

  python scripts/capture_multi_band_serial.py PORT [-o output.csv]
    Capture from Arduino to CSV (default: data/multi_band_timeseries.csv). Ctrl+C to stop.
    Example: python scripts/capture_multi_band_serial.py /dev/cu.usbmodem14101

Other scripts
-------------
  python scripts/cholesterol_peuchant_nir.py
    Peuchant 1987 NIR (synthetic reflectance). TC/LDL from 7-wavelength formula. NOT for medical use.

  python scripts/plot_pulse_ox_fft.py [CSV]
    FFT on color-band CSV (elapsed_sec, R, G, B). Default: data/pulse_ox_color_timeseries.csv

  python scripts/yom_series_fft.py [raw.txt]
    Parse Arduino dump, save CSV, FFT, bandpass. Default: data/yom_arduino_series_raw.txt

  python scripts/validate_peuchant_nir.py
    Validate Peuchant NIR formula on synthetic data.

  python scripts/counts_to_absorption.py
    Counts → absorption A = -log10(I/I0); reflectance R = 10^(-A).

Sensor → reflectance for Peuchant NIR
-------------------------------------
  See docs/sensor_to_reflectance.md: counts → absorption; reflectance at 7 wavelengths
  (2208, 2190, 1940, 1734, 1722, 1445, 1680 nm) for TC formula.
